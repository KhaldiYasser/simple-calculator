# 🧮 Web Calculator App

A browser-based **Calculator Application** built with **HTML5**, **CSS3**, and **Vanilla JavaScript**. It offers a clean, dark-themed user interface to execute basic arithmetic operations directly in the browser[cite: 21, 23].

---

## 📸 Features

* **Basic Arithmetic Operations:** Supports addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
* **Display Controls:** Instant screen clear using the `C` button and result evaluation using the `=` button[cite: 21, 22].
* **Error Handling:** Displays an `"error"` message if an invalid mathematical expression is evaluated.
* **Modern UI:** Styled with rounded circular buttons and visual state feedback for `hover` and `active` interactions[cite: 23].

---

## 🛠️ Built With

* **HTML5** - Screen layout and button key structure.
* **CSS3** - Responsive arrangement using Flexbox and HSL color styling[cite: 21, 23].
* **Vanilla JavaScript** - Input appending, screen clearing, and dynamic mathematical evaluation via `eval()`[cite: 21, 22].
